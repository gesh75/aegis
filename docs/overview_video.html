Closed loop · with a human

Validated → approved → pushed. Never automatic.

A deterministic approval gate promotes only verified, human-authorized changes. Blocked, tampered, or unapproved changes are denied. AEGIS never mutates production on its own — the push is deliberate, gated, and recorded.
